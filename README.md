# USACO Solutions All Divisions

This repository serves the purpose as easy access for USACO problem solutions. Problems are divided by division in which they appeared in no particular order (i.e. they are not sorted by year). A solution's name is consistent with the input/output file names (if they exist), otherwise the name will resemble the original name.

The solutions should be primarily written in C++, but (where it makes the implementation particularly easy) Python may be used as well, mostly in Bronze problems.

## Purpose

This repo comes as an extension to the "7 Bit Wonders" channel, where each solution is broken up into all the necessary components in order to implement it efficiently and correctly; that is, it's **highly recommended** to check out the full video explanation if you want a deeper walkthrough.

## Work-in-Progress

As of now, the repository is a work in progress and is actively worked upon to maintain quality and volume (it's qite useless if barely a few problems are solves). If you notice any issues with the code, **please let me know** so that I can rectify it asap.
